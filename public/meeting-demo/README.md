# Across · 跨时区会议高保真原型

双击 index.html 可查看；部署 Be better 后访问 `/meeting-demo/index.html`。
可用 `?step=0`（排期）、1（会中协作）、2（待办确认）、3（任务接力）直达场景。

基于用户确认的墨刀 V2 流程与 D/E 视觉方向，整理为本地独立 HTML 原型，不修改云端墨刀工程。
人物、日期、字幕、纪要和任务均为演示数据；AI、会议音视频、通知、任务分发与数据库没有连接。
交互涵盖时间候选、主持人主动邀请/忽略、三语摘要、负责人和日期确认、阻塞方案人工选择。
本地会话只保存表达草稿和第三项截止日期。无外部第三方素材和运行依赖。
