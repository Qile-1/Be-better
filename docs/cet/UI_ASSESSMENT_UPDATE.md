# 诊断、补讲与课程地图更新

2026-10-11，承接五年内容规范后的调整。

## 实施

- 阅读、写作、翻译分别传入适合方法复述的考评规则；共享当前课程标题、任务、要点 tier、能力和常见错误。
- 课程重点／拔高决定学习顺序，本节核心／拓展决定评估范围，两者分别处理。准确的自己的话和多种表达允许，拓展遗漏不计硬伤。
- 诊断按服务器核对后的核心覆盖和错误列表返回结果。错误关联本节真实 pointId，讲错的点不算覆盖；硬伤数量取错误列表长度，异常结构会重试。
- 补讲先纠错，再补当前核心遗漏。相同目标合并，过滤无关补讲，缺少目标则重试。每次未达标的新诊断重新生成补讲，旧请求不覆盖新结果。
- 保持已有三档掌握度阈值、全程开放课程及按 lessonId 存储进度。课程序号和下一节顺序随模块内“重点优先”更新。
- 课程地图桌面三列、移动单列；模块间距缩小，标题用衬线字形，课程名称加粗，行间分隔。模块内重点在前，拔高在后，放入浅绿色边框和背景区域。
- 微课拓展、拓展讲义要点、诊断拓展结果使用浅绿色区域；知识点条目增加分隔。
